# Mohammed Umar & Marziya — Walima invitation

A mobile-first, single-page animated invitation (Vite + vanilla JS + GSAP + WebGL).
Guests pull a gold tassel to open the curtain, then scroll one continuous, smooth column (Lenis)
with every card shown whole, like a phone; on wide screens a blurred copy of the card in view fills the sides.

## Run it locally

Requirements: Node 18+ (and Python 3 only if you want to regenerate the artwork assets).

```powershell
npm install
npm run dev
```

Open the printed URL (e.g. http://localhost:5173). The `--host` flag also prints a LAN address so you
can open it on your phone while on the same Wi-Fi.

Production build:

```powershell
npm run build
npm run preview
```

The finished static site is in `dist/`.

> The project folder name contains `&`, which breaks the `node_modules/.bin` shims on Windows, so the
> npm scripts call Vite through `node node_modules/vite/bin/vite.js`. Use `npm run …`, not `npx vite`.

## Adding or swapping the music

1. Put the track at **`assets/audio/music.mp3`** (exactly that name).
2. Rebuild: `npm run build` (the dev server picks it up automatically).

It starts when the guest pulls the tassel, fades in to 60% volume over 3 seconds, loops, and pauses
when the tab is hidden. If the file is missing or fails to load, the music button simply doesn't appear.
To change the track later, replace the file and rebuild.

## Deploying

**Netlify (drag and drop):** run `npm run build`, then drag the `dist/` folder onto
<https://app.netlify.com/drop>.

**Vercel:** import the folder/repo; the framework preset is "Vite" (build command `npm run build`,
output directory `dist`). Or with the CLI (`npm i -g vercel` once), run `vercel --prod` in the project
folder and accept the defaults. Either way only `dist/` is served.

**Link previews (WhatsApp, etc.):** WhatsApp works best with an absolute image URL. Once you know
the final address, build with it:

```powershell
$env:SITE_URL = "https://your-site.netlify.app"; npm run build
```

Netlify and Vercel CI builds set this automatically. Without it, `og:image` is relative
(`og-image.jpg`), which most apps resolve but some may not.

## How it's put together

| Path | What it is |
| --- | --- |
| `assets/original/` | The six original artworks — never modified. |
| `tools/prepare_assets.py` | One-time asset prep (Pillow + OpenCV + NumPy). Re-run with `npm run assets`. |
| `assets/generated/` | Its output: text-free "clean plates", text sprites, motion masks, responsive WebP, OG image, icons. `masters/` and `debug/` hold lossless masters, mask overlays and diff proofs (not shipped). |
| `src/layout.json` | Every position (text blocks, oval, fountain, candles, tassel anchor, …) as % of its image. Generated by the prep script. |
| `src/living.js` | WebGL "living image" shader: the motion mask's R = breeze, G = water, B = fabric. Also renders the curtain opening. |
| `src/intro.js` | Preloader, verlet pull-cord tassel, opening sequence. |
| `src/pages.js` / `src/scratch.js` | Pages 2, 4–6 / the page 3 scratch card (pearl cover + sweeping sheen). |
| `src/main.js` | Column layout, Lenis smooth scrolling, side backdrop, reveal-on-scroll. |
| `src/fx.js` | Canvas particles: gold dust, candle flicker, petals, fountain spray, confetti. |
| `tools/verify.mjs` | Playwright checks + screenshots/recordings → `verify/` (run against the dev server). |

The artwork's wording and dates are untouched. The text you see is the original pixels: each line is
cut out as a sprite, and clean plate + sprites reproduce the original to within 2/255 (proofs in
`assets/generated/debug/page*_diff_x10.png`).

Verification: with `npm run dev` running, `npm run verify` (first time: `node node_modules/playwright/cli.js install chromium`).
